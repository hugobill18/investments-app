📅 Capacité Équipe

Bienvenue 👋

Cette application gère les congés, télétravail et absences des équipes. Les données sont stockées dans un dossier partagé (par exemple un dossier OneDrive/SharePoint synchronisé sur votre PC). Choisissez ce dossier pour commencer.

Astuce : sélectionnez le dossier donnees du OneDrive partagé par votre responsable. Le navigateur vous demandera l'autorisation de lecture/écriture : cliquez sur « Autoriser ».

Votre navigateur ne permet pas l'accès aux dossiers locaux (API File System Access absente). Utilisez Microsoft Edge ou Google Chrome.

Première utilisation — configuration

Ce dossier ne contient pas encore de données. L'organisation de base (équipes, personnes, lieux Paris / Lisbonne / Kuala Lumpur / Tunis avec leurs fériés) sera créée automatiquement — le tout modifiable ensuite dans Paramètres. Saisissez votre nom : vous serez administrateur (si le nom correspond à une personne de l'organisation, elle est reconnue).

Qui êtes-vous ?

Sélectionnez votre nom. Pour une connexion automatique, lancez l'application via Lancer.cmd et demandez à un administrateur d'associer votre login Windows dans Paramètres.
