📅 Team Capacity

Welcome 👋

This application manages the team's leave, remote work, and absences. Data is stored in a shared folder (for example a OneDrive/SharePoint folder synced to your PC). Choose that folder to get started.

Tip: select the data folder in the OneDrive shared by your manager. The browser will ask for read/write permission: click "Allow".

Your browser doesn't support local folder access (the File System Access API is missing). Use Microsoft Edge or Google Chrome.

First-time setup

This folder doesn't have any data yet. The default organization (teams, people, locations — Paris / Lisbon / Kuala Lumpur / Tunis — with their public holidays) will be created automatically — all of it editable afterwards in Settings. Enter your name: you'll become an administrator (if the name matches a person in the organization, they'll be recognized).

Who are you?

Select your name. For automatic sign-in, launch the app via Lancer.cmd and ask an administrator to link your Windows login in Settings.
