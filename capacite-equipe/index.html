📅 Capacité Équipe

Bienvenue 👋

Cette application gère les congés, télétravail et absences de l'équipe. Les données sont stockées dans un dossier partagé (par exemple un dossier OneDrive/SharePoint synchronisé sur votre PC). Choisissez ce dossier pour commencer.

Astuce : sélectionnez le dossier OneDrive partagé par votre responsable (ex. Documents partagés > Capacité Équipe > donnees). Le navigateur vous demandera l'autorisation de lecture/écriture : cliquez sur « Autoriser ».

Votre navigateur ne permet pas l'accès aux dossiers locaux (API File System Access absente). Utilisez Microsoft Edge ou Google Chrome.

Première utilisation — configuration

Ce dossier ne contient pas encore de données. Créez le premier compte (il sera administrateur) et les jours fériés seront générés automatiquement.

Qui êtes-vous ?

Sélectionnez votre nom. (Identification déclarative — voir la note de l'administrateur sur les limites de confidentialité.)
