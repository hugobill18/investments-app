✅ API Unifiée
  - getQuote(ticker)              → Détecte stock/crypto/devise
  - getPrices(tickers)            → Batch optimisé
  - getLivretRates()              → Taux Banque de France
  - convertCurrency()             → Conversion devise

✅ Cache Intelligent
  - TTL : 30 minutes (configurable)
  - Stats/monitoring
  - Prune automatique

✅ Orchestration des sources
  - Yahoo Finance : Stocks, Indices, Devises
  - CoinGecko : 16+ cryptos
  - Banque de France : Livrets

✅ Routes Express
  - GET /api/quote/:ticker
  - POST /api/quotes/batch
  - GET /api/livret-rates
  - POST /api/convert
  - GET /api/cache/stats
  - POST /api/cache/clear

✅ Gestion d'erreurs
  - Timeouts (8s)
  - Fallbacks
  - Logging complet
  - Messages clairs

✅ Performance
  - Cache hit : ~10ms
  - Cache miss : ~1s
  - Batch : ~2s pour 5 tickers

================================================================================
                          🚀 UTILISATION
================================================================================

Démarrer le serveur :
  $ cd investments-app && npm start

Tester les APIs :
  $ curl "http://localhost:3000/api/quote/AAPL"
  $ curl -X POST http://localhost:3000/api/quotes/batch \
      -H "Content-Type: application/json" \
      -d '{"tickers":["AAPL","BTC","MSFT"]}'
  $ curl "http://localhost:3000/api/livret-rates"

Exécuter les tests :
  $ node test-api-providers.js

Voir les stats du cache :
  $ curl "http://localhost:3000/api/cache/stats"
